# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please don't report security issues in public issues, pull requests or discussions, and
don't send them by email.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/tefra/xsdata/security/advisories/new).
Include the affected version, the steps to reproduce and the impact.

Reports are handled in a draft security advisory. Fixes are released before the advisory
is published, and reporters are credited in the advisory.
